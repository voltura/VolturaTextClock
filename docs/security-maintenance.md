# Historical code-scanning reconciliation

Reviewed 2026-11-03 for the v1.1.0 revival. The 170 open Codacy/Sonarscharp alerts all came from commit e83f710868c12aa0866116552276db14bd46f46a, analyzed on 2020-12-29. They comprise 89 notes and 81 warnings; they are not a count of confirmed current vulnerabilities.

Each alert was compared with the current implementation, including moved form paths, the replacement Graphics renderer, SDK-generated assembly metadata, local logging, settings persistence, and resource-backed clock calculation. Static triage found no confirmed security finding in this supplied collection. This is not an exhaustive security audit. Current CodeQL and dependency monitoring supply a new baseline.

The table retains one entry per alert. “false positive” means obsolete analysis or a claim defeated by current source; it does not relabel every original issue as a false alarm at the time. “won't fix” explicitly accepts a non-security style convention, with the evidence stated. The logging short-read issue, unused exception-producing getter, and redundant constructor were fixed during the revival. Do not delete historical analyses to make the count disappear.
